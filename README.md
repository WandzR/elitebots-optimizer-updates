# ELITEBOTS Optimizer

Instaladores Windows x64 e atualizações automáticas verificadas com assinatura Ed25519 própria ELITEBOTS.

Baixe a beta em [Releases](https://github.com/WandzR/elitebots-optimizer-updates/releases).

O código-fonte fica em repositório privado. Este repositório distribui apenas instaladores, metadados de atualização e a automação de publicação.

A beta.1 precisa ser substituída uma vez pela beta.2 ou posterior para ativar as atualizações automáticas.
